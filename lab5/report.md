# Лабораторная работа №5: Запуск MPI-версии на суперкомпьютере

## Задание

Параллельную версию программы на MPI из лабораторной работы №3 необходимо запустить на суперкомпьютере «Сергей Королёв».

- **Исходные данные:** файлы со значениями исходных квадратных матриц A и B
- **Выходные данные:** файл со значениями результирующей матрицы C, время выполнения, объём задачи
- **Верификация:** автоматизированная проверка результата через Python/NumPy
- **Технология:** MPI, запуск через пакетную систему суперкомпьютера

## Описание реализации

В лабораторной работе используется та же схема распараллеливания, что и в л/р №3: строки матрицы A распределяются между MPI-процессами, а транспонированная матрица B рассылается всем процессам.

Алгоритм:

1. Процесс 0 считывает матрицы A и B из файлов.
2. Матрица B транспонируется для последовательного доступа во внутреннем цикле.
3. Размер матрицы и транспонированная B рассылаются через `MPI_Bcast`.
4. Строки матрицы A распределяются через `MPI_Scatterv`.
5. Каждый процесс вычисляет свой блок строк результата.
6. Результат собирается на процессе 0 через `MPI_Gatherv`.
7. Процесс 0 сохраняет матрицу C и выводит CSV-строку с метриками.

Формула объёма вычислений:

**F = 2n^3 - n^2**

## Исходный код

Основной файл решения: `src/main.cpp`.

Ключевая часть распределения данных:

```cpp
MPI_Bcast(&n, 1, MPI_INT, 0, MPI_COMM_WORLD);
MPI_Bcast(bt.data(), n * n, MPI_INT, 0, MPI_COMM_WORLD);

MPI_Scatterv(a_full.data(), elem_counts.data(), elem_displs.data(), MPI_INT,
             local_a.data(), my_rows * n, MPI_INT, 0, MPI_COMM_WORLD);

for (int i = 0; i < my_rows; i++) {
    for (int j = 0; j < n; j++) {
        int acc = 0;
        for (int k = 0; k < n; k++)
            acc += local_a[i * n + k] * bt[j * n + k];
        local_c[i * n + j] = acc;
    }
}

MPI_Gatherv(local_c.data(), my_rows * n, MPI_INT,
            c_full.data(), elem_counts.data(), elem_displs.data(), MPI_INT,
            0, MPI_COMM_WORLD);
```

Формат вывода программы:

```text
n,processes,flops,time_sec,mflops
```

## Запуск на суперкомпьютере

Для пакетного запуска подготовлены два варианта:

- `start/startMPI.slurm` - скрипт для SLURM
- `start/startMPI.pbs` - скрипт для PBS/Torque

Пример SLURM-скрипта:

```bash
#!/bin/bash
#SBATCH --job-name=lab5_mpi_matrix
#SBATCH --partition=batch
#SBATCH --nodes=1
#SBATCH --ntasks-per-node=40
#SBATCH --time=00:10:00
#SBATCH --output=results/slurm-%j.out

module purge
module load intel/mpi5

make
python3 scripts/generate_matrix.py -n "${MATRIX_SIZE:-2000}" -d data
mpirun -np "${SLURM_NTASKS:-40}" ./matrix_mul_mpi_super data/matrix_a.txt data/matrix_b.txt data/result.txt
python3 scripts/verify.py data/matrix_a.txt data/matrix_b.txt data/result.txt
```

Команды запуска:

```bash
make
sbatch start/startMPI.slurm
```

или для PBS:

```bash
make
qsub start/startMPI.pbs
```

## Верификация

Для проверки корректности используется `scripts/verify.py`. Скрипт загружает A, B и C, вычисляет эталонный результат через NumPy:

```python
expected = a @ b
```

и сравнивает его с результатом MPI-программы поэлементно.

Локальная проверка:

```bash
make test
```

Результат проверки:

```text
500,4,249750000,0.001842,135586
OK  500x500
```
